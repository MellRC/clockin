# 工力全开

![首页](docs/home.png)

安卓打卡提醒。到了设定时间，在公司范围内提醒你打开企业微信。数据只存在本机，应用没有网络权限。

打开企业微信不代表已经打卡。自动结果识别还没做，需要你自己核对。

## 能做什么

- 四个时段：上班、午间下班、午间上班、下班
- 上班、午间上班、下班的有效窗口是 60 分钟；午间下班覆盖整个午休
- 大小周、固定双休、固定单休
- 提醒模式会亮屏震动；静默模式不主动亮屏、无声无震，两种模式都可在锁屏时尝试预启动打卡页
- 打开应用时，还在有效时间内且这次还没开始的时段会补一次

## 企业微信打卡页直达

- 使用 `ACTION_VIEW` 打开 `wxwork://jump?target=punch&tab=1`，限定企业微信包 `com.tencent.wework`。不会关闭、强停企业微信，也不清理旧任务栈。
- 有效任务触发、定位等条件满足且无障碍服务已连接时，锁屏期间最多提交一次预启动请求。系统可能拦截后台启动，提交请求不代表页面已打开。
- 真正解锁后，若已提交预启动且观察到企业微信在前台，不重复自动跳转；否则走解锁后的链接回退。通知点击和首页“立即试开”也使用同一链接。
- 企业微信已在前台也会响应首次/手动链接请求；但只观察包名，不能核验当前是打卡页，更不能核验打卡成功。
- 链接没有可用处理入口时明确提示，不悄悄退回企业微信首页。实际跳转效果依赖手机系统、后台权限、企业微信版本和登录状态，需要真机验证。

## 构建

需要 JDK 17、Android SDK（compileSdk 35）和 Gradle 8.9。

```
gradle :app:assembleDebug
```

安装包在 `app/build/outputs/apk/debug/`。
